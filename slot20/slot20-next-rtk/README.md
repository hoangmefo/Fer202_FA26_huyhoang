# Slot 20 — Next.js + Tailwind CSS + Redux Toolkit

This project currently implements **Bài 1: Khởi tạo project + Store + Counter**
from `D:\ky5\tai_lieu\Slot20.md`.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000/counter> to try the counter. The project uses Next.js
App Router, TypeScript, Tailwind CSS v4, and Redux Toolkit. Redux DevTools can
inspect dispatched actions when the browser extension is installed.

## Included in Bài 1

- Per-provider Redux store factory and typed React Redux hooks.
- Counter slice with increment, decrement, reset, custom amount, and step actions.
- Server-rendered home and counter routes with a client-side counter component.
